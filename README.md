# QADAM 2.0 · толық сайт пакеті

Бұл — GitHub Pages-ке бірден жүктеуге арналған QADAM математикалық платформасының толық статикалық пакеті. Сайт 14 беттен, 2 400 есептен, жауапты автоматты тексеруден, ишаралар мен шешу жолдарынан, сынақтан, прогресс журналынан және бөлек Cloudflare AI Worker кодынан тұрады.

## Не бар

- 5 және 6-сынып: әрқайсысына 1 200 есеп.
- 6 тақырып: пайыз, бөлшек, өзгеретін бүтін, тиімді есептеу, геометрия, логика.
- 4 деңгей: жеңіл, орташа, күрделі, олимпиадалық.
- Әр сынып × тақырып × деңгей ұяшығында дәл 50 есеп.
- Барлығы 2 400 бірегей есеп; әр есепте жауап, ишара және шешу жолы бар.
- Есептер банкі 60 есептен беттеледі, сынып/тақырып/деңгей/күй бойынша сүзеді.
- Жауапты тексеру, 10 есептік сынақ, қате зертханасы, прогресс және сақталған есептер.
- Прогресс браузердің `localStorage` жадында сақталады.
- AI менторға арналған қауіпсіз Cloudflare Worker коды `qadam-ai-worker/` ішінде.

## Негізгі құрылым

```text
index.html                 басты бет
tasks.html                 2 400 есеп банкі
courses.html               оқу картасы
lesson-*.html              6 теориялық тарау
lab.html                   интерактивті зертхана
errors.html                қате талдау
challenge.html             10 есептік сынақ
journal.html               прогресс журналы
mentor.html                AI ментор интерфейсі
data/questions.json        ашық 2 400 есеп дерегі
js/questions.js            браузерге арналған сол дерек
js/data.js                 тақырыптар мен оқу мазмұны
js/app.js                  сайт логикасы
qadam-ai-worker/           Cloudflare Workers AI сервері
tests/                     дерек пен сайт тексерістері
```

## Жергілікті ашу

Python бар болса, сайт бумасында `python3 -m http.server 8000` орындап, `http://localhost:8000` ашыңыз. Негізгі беттер интернетсіз жұмыс істейді; AI ментор үшін Worker URL-і қажет.

## Автоматты тексеру

Node.js орнатылған компьютерде:

```bash
npm test
```

Тест 2 400 жауапты формулалардан қайта есептейді, үлестірімді санайды, қайталанатын ID/есептерді, JavaScript синтаксисін және барлық HTML беттегі жергілікті файл сілтемелерін тексереді.
