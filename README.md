# QADAM · интерактивті математикалық платформа

## Ішінде

14 отдельных HTML-страниц: личная панель; карта обучения; 6 теоретических глав; банк из 60 проверяемых задач; визуальная лаборатория процентов, дробей и геометрии; 8 разборов типичных ошибок; 10-вопросный смешанный тест; журнал прогресса; чат с Cloudflare Workers AI.

Ответы в задачах проверяются по отдельным ключам. В открытых заданиях система показывает пример и критерии самооценки, но не выдаёт автоматическую оценку. Прогресс сохраняется в localStorage конкретного браузера.

## Локальный просмотр

В папке сайта запустить `python -m http.server 8000`, затем открыть `http://localhost:8000`. Для проверки всех страниц использовать ссылки бокового меню.

## GitHub Pages

Загрузить всё содержимое этой папки вместе с `assets` и `js` в корень репозитория. В GitHub выбрать **Settings → Pages → Deploy from a branch → main / (root)**. При открытии страницы index.html станет домашней панелью.

## Workers AI

Отдельный код Worker находится в папке `qadam-ai-worker`. После его публикации заменить значение `AI_API_URL` в `js/ai.js` выданным URL. Настроить разрешённый GitHub Pages origin в wrangler.jsonc. До подключения AI остальные разделы и задачи работают самостоятельно.
